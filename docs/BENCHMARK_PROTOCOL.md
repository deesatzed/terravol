# Benchmark protocol to freeze before fitting

Authoritative science and promotion rules: [GOAL_UPD.md](../GOAL_UPD.md) §§18–20, 24. **No application benchmark or prospective study has run.**

## Independent questions

1. Information value: temporal forecasts versus known calendars versus historically predicted event/exposure features.
2. Structural value: same-information numerical control versus ESS transmission, then direct cross-market versus dependency-aware cascade modeling.
3. Allocation value: same expert pool with equal/global/rolling/feature/event gates; then full/fixed versus cheap selective execution.
4. Investigation value: fixed/random/disagreement/learned acquisitions at matched budgets and the same reissue time/future target.
5. Monitoring value: top-probability/random/cheapest/overlap-aware selection with explicit observation laws, lead time and frozen utility.

Each added mechanism requires a removal ablation. A better model pool is a different treatment from a better gate. More scenario coverage is a different result from better calibrated downstream forecasts or timely alerts.

## Before any confirmation data are opened

Freeze task identity, estimator/units, instruments/contracts, origins, horizons, event definitions/resolution rules, first-release policy, availability assumptions, candidate graph/monitor universe, expert pool, budgets, target matching/clusters, score normalization, primary comparison, multiplicity policy, practical/calibration/tail margins and required independent sample support. Track every tried configuration and holdout opening.

Use expanding/rolling outer evaluation with strictly earlier tuning/calibration. Purge label overlap including publication and episode-confirmation delays. Cross-fit event forecasts, expectation proxies, transforms, reference models, transmission corrections, dependence adapters and gates. Group storms/episodes across forecasts and instruments. Full-sample smoothed states and hindsight realized branches are oracle diagnostics, not deployable inputs.

## Scores and status

Use CRPS or supported quantile/WIS representations; QLIKE only for a valid conditional variance mean and declared zero/floor policy. Score occurrence/joint events with proper probability losses and timing/duration with censoring-aware methods. Add joint distribution scores plus targeted tail/episode diagnostics. Report calibration, false/missed alerts, useful lead time, failed/abstained origins and full resource costs by instrument/horizon/event/context.

No archived weather realization substitutes for an as-issued forecast. Unknown pretrained overlap and historical LLM outcome knowledge limit retrospective claims; prospective frozen observations are a separate gate. Missing provider rights/coverage produce a blocked real-data track while independent synthetic engineering proceeds.

Retain a simpler incumbent for negative/inconclusive/underpowered results. The historical 3% planning target is configurable and not an observed gain. Publish engineering, scientific, prospective and economic states separately; no optional economic assessment is required for a useful variance forecaster.
