## Open decisions that require evidence

- Exact authorized market/contract dataset, weather model/run/member archive, overlapping history and availability certification; consensus provider/rights if used.
- Target sampling/session/revision policies and a validated measurement link for each return-variance model. Preserve proxy versus intraday identity.
- Exact checkpoint revisions, package intersection, terms, Mac memory/latency and output capabilities. Source documentation is not a local smoke test.
- Monitor cadence, observation/error/arrival law, minimum useful lead time, utility/cost coefficients, and candidate episode population before monitoring experiments.
- Fitted graph size, exposure hierarchy, delay priors/shrinkage, evaluation clustering, practical improvement margins and fresh confirmation windows before fitting/selection.

## Future decision rule

Record date, trigger, alternatives, chosen behavior, affected interfaces/tests and evidence. Learners cannot revise permissions, label definitions, benchmark splits or source rights. Structural production changes require the specified promotion review; ordinary reversible implementation within the active scope does not require another architecture approval at every step.
